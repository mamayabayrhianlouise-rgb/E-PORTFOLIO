# Rhian Louise L. Mamayabay | Electronic Professional Portfolio

## About the Project

This project is my Electronic Professional Portfolio, created to present my personal information, educational background, skills, achievements, and projects in one website.

The portfolio serves as a digital introduction to who I am as an IT student and aspiring web designer. It allows visitors to learn more about my background and the skills I am developing in the field of technology.

## Objectives

- To introduce myself and my educational background.
- To showcase my skills, achievements, and projects.
- To organize my professional information in one website.
- To demonstrate my knowledge of web development.
- To create an online portfolio that can be accessed easily.

## Technologies Used

- **HTML** – Structures the content of the website.
- **CSS** – Designs the layout, colors, and overall appearance.
- **JavaScript** – Adds interactive features to the website.

## Features

- Personal introduction and profile
- Educational background
- Skills and interests
- Achievements and certificates
- Projects and other portfolio information
- Responsive website layout

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Find the `index.html` file.
4. Open `index.html` in your web browser.
5. Explore the different sections of the portfolio.

## Project Purpose

This portfolio was created as part of my learning journey in Information Technology. It showcases my progress, skills, and experiences while helping me build my professional identity in web design and development.
